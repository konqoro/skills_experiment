# Task

Create raw Nim bindings for the supplied `benchffi` C library and a small
executable that proves the bindings work after relocation.

## Deliverables

- `benchffi_raw.nim`
- `smoke.nim`

## Inputs and Fixtures

The trial contains:

- `fixtures/benchffi.h`
- `fixtures/benchffi.c`

Treat the header as the API specification. The C source is provided to build
the shared library used by the smoke run.

The environment is Linux with a C compiler and Nim available.

## Required Behavior

`benchffi_raw.nim` must expose a low-level binding for the complete public API
in `fixtures/benchffi.h`. Keep it as a raw binding module; conversions and
resource-management wrappers are outside this task.

`smoke.nim` must import that module and:

- create a config with bias `2`, scale `3`, and label `"alpha"`
- open a handle and check that it is non-nil
- push `[1, 4, 7]` as signed C integers
- check the returned status code and message against the header contract
- read a snapshot and check count `3`, total `54`, mean `18.0`, and checksum
  `156834`
- check that the label is `"alpha"`
- close the handle once
- print exactly `SMOKE: PASS`

The executable and shared library must still work when copied together into a
fresh run directory. Do not require the caller to set loader environment
variables.

## Required Commands

Run these commands from the trial directory:

```bash
mkdir -p build run
cc -shared -fPIC fixtures/benchffi.c -Ifixtures -o build/libbenchffi.so
nim c --nimcache:build/nimcache --out:build/smoke smoke.nim
cp build/smoke build/libbenchffi.so run/
cd run
./smoke
```

## Judge Checklist

- The required commands succeed from a fresh trial directory and the relocated
  executable prints exactly `SMOKE: PASS`.
- `benchffi_raw.nim` directly imports every public function declared by
  `fixtures/benchffi.h`; the imported declarations have no Nim bodies.
- The handle is represented without declaring the private C struct layout.
- Config, snapshot, and status preserve the C field order and use
  ABI-compatible field types. Structs passed or returned by value are declared
  for by-value C ABI use.
- Both status macros are exposed as raw constants with the header values.
- Pointer-plus-length input remains pointer-plus-length in the raw module.
- `smoke.nim` uses the raw declarations directly and closes the opened handle
  exactly once.
- Neither deliverable compiles `fixtures/benchffi.c` into the Nim executable or
  adds a second Nim-bodied binding/wrapper for a public C function.
- Removing `run/libbenchffi.so` makes `run/smoke` fail to start or load the
  API, proving the executable uses the staged shared library.
- The source and executable contain no machine-specific absolute library path
  or trial build-directory runtime path.
- Runtime discovery works without `LD_LIBRARY_PATH`, `DYLD_LIBRARY_PATH`, or
  `PATH` changes.
